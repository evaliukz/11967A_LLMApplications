# 1. What’s an embedding?

An embedding is a dense vector representation of a token. It converts a discrete token ID into a continuous space where the neural network can learn semantic and contextual relationships.

更短版：An embedding maps a discrete token into a continuous vector representation that the model can process.

# 2. What’s an encoder?

An encoder takes the input sequence and transforms each token into contextualized hidden representations. In a Transformer encoder, this is mainly done through self-attention and feed-forward layers.

你可以再补一句：

Each output hidden state contains information not just about that token, but also about other relevant tokens in the input sequence.

# 3. What’s a decoder?

A decoder generates the output sequence autoregressively. It uses the previously generated tokens, and in an encoder-decoder model it can also attend to the encoder outputs, to predict the next token distribution.

更容易说的版本：

The decoder takes the output tokens generated so far and predicts the next token, one step at a time.

# 4. What’s Encoder-Decoder Attention?

也叫 Cross-Attention。

Encoder-decoder attention lets the decoder retrieve relevant information from the encoder outputs. The queries come from the decoder, while the keys and values come from the encoder.

加一句直觉：For example, in translation, when generating an English word, the decoder can focus on the most relevant words in the source sentence.

# 5. What’s Self-Attention?

Self-attention allows each token in a sequence to directly attend to other tokens in the same sequence. It helps the model build contextualized representations and capture long-range dependencies without recurrent computation.

核心一定要说：In self-attention, the queries, keys, and values all come from the same sequence.

# 6. What’s Masked Self-Attention?

Masked self-attention is self-attention with a causal mask that prevents each position from attending to future tokens. This preserves the autoregressive property needed for next-token prediction.

举例：When predicting token 4, the model can attend to tokens 1 through 3, but not token 5 or later.

# 7. What’s Multi-Headed Attention?

Multi-head attention runs several attention operations in parallel using different learned projections. This allows the model to capture different types of relationships between tokens in different representation subspaces.

再简单一点：Instead of looking at the sequence in only one way, multiple heads let the model learn several attention patterns at the same time.

# 9. Tell me about Q, K, and V.

这是最值得你练熟的一题。

Query represents what the current token is looking for, key represents what each token can be matched on, and value contains the information that will actually be aggregated. We compare queries with keys to get attention scores, normalize them with softmax, and use those weights to compute a weighted sum of the values.

最好记住这个口语化版本：The query asks, the key matches, and the value provides the information.

如果面试官继续问公式：In scaled dot-product attention, we compute softmax(QKᵀ / sqrt(d_k)) V.

### QKV 再给你一个真正容易理解的例子

假设 sentence 是：“The animal didn’t cross the street because it was tired.”

处理 it 时：

Query of “it”：我现在要找跟 it 相关的信息。

Keys of all tokens：每个 token 提供一个“可以被匹配的标签”。

animal 的 key 和 it 的 query 很匹配，所以得到高 attention score。

Value of “animal” 中的信息因此被大量加入 it 的新 representation。

所以你可以在面试里说：Q and K determine where to attend, while V determines what information to retrieve. 这句非常好用。

# 10. Walk me through the LLM architecture

你可以按照图 从下往上、先 Encoder 再 Decoder 说。

Starting from the bottom, the input tokens are first converted into token embeddings, and positional encodings are added because attention itself does not encode token order.

On the encoder side, the representations go through repeated Transformer blocks. Each block contains multi-head self-attention, followed by a feed-forward network, with residual connections and layer normalization around each sublayer. The self-attention allows every input token to incorporate information from other input tokens.

On the decoder side, we also start with token embeddings plus positional information, but the first attention layer is masked self-attention. The mask prevents the decoder from looking at future output tokens.

The decoder then performs encoder-decoder, or cross-attention. Here the queries come from the decoder, while the keys and values come from the encoder outputs, so the decoder can retrieve the source information that is most relevant for the current prediction.

After that, the representation passes through a feed-forward layer. These decoder blocks are stacked multiple times, and finally the decoder output goes through a linear projection and softmax to produce a probability distribution over the vocabulary for the next token.

## 三个 Attention block 问区别

你直接这样答：

The encoder self-attention lets input tokens attend to other input tokens. The decoder masked self-attention lets output tokens attend only to previous output tokens. The encoder-decoder attention lets decoder queries attend to encoder keys and values.

这一句话非常值得背。

## 问 Add & Norm

Add refers to the residual connection, where the sublayer output is added back to its input. Norm refers to layer normalization, which helps stabilize training.

## 问Feed Forward

The feed-forward network is a small MLP applied independently to each token position. Attention mixes information across tokens, while the feed-forward layer transforms each token representation locally. 这句也是很好的区分。

## 为什么 Transformer 不用 RNN

RNNs process tokens sequentially, which limits parallelism and makes long-range dependencies harder to preserve. Self-attention allows tokens to interact directly and enables much more parallel computation during training.
