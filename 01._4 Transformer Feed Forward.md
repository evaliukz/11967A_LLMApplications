# Transformer Feed-Forward Network (FFN) 详细笔记

## 1. Feed Forward 是什么？

Transformer Decoder Block 里有两个非常重要的计算：

``` text
Masked Self-Attention
→ Add & Norm
→ Feed-Forward Network (FFN)
→ Add & Norm
```

最重要的区别：

> **Self-Attention 负责让不同 token 之间交换信息；Feed Forward负责对每一个 token 自己的 representation 做非线性加工。**

英文记忆：

> **Attention mixes information across tokens; the FFN transforms
> information within each token.**

可以把它类比成：

``` text
Attention = 大家开会，互相交流
FFN       = 开完会后，每个人独立思考
```

------------------------------------------------------------------------

## 2. 作业里的 FFN 结构

``` python
middle_dim = 4 * n_embd
self.linear_in = nn.Linear(n_embd, middle_dim)
self.linear_out = nn.Linear(middle_dim, n_embd)
self.dropout = nn.Dropout(p_dropout)
```

令：D = n_embd

那么：middle\_dim = 4D

整个 FFN：

``` text
D
↓ Linear
4D
↓ GeLU
4D
↓ Linear
D
↓ Dropout
D
```

数学公式：

$$
FFN(x)=
Dropout
\left(
GeLU(xW_1+b_1)W_2+b_2
\right)
$$

------------------------------------------------------------------------

## 3. 输入 `x`

输入：x.shape = [B,S,D]

其中：

``` text
B = batch size
S = sequence length
D = hidden dimension = n_embd
```

例如：

``` text
B = 2
S = 5
D = 768
```

那么：x.shape = [2,5,768]

意思是 2 个 sequences，每个有 5 个 token，每个 token 当前用一个 768 维vector 表示。

------------------------------------------------------------------------

## 4. FFN 是 Position-wise 的

假设 sequence：I love cats

Attention 后：

``` text
I    → h1
love → h2
cats → h3
```

FFN 分别计算：

$$
FFN(h_1)
$$

$$
FFN(h_2)
$$

$$
FFN(h_3)
$$

每个 token 独立经过同一套 FFN parameters。

所以它叫：**Position-wise Feed-Forward Network**

FFN 本身不会重新让 `I`、`love`、`cats` 互相做 attention。

------------------------------------------------------------------------

## 5. Step 1：Linear In，把 D 扩展成 4D

``` python
self.linear_in = nn.Linear(D, 4 * D)
```

所以：

``` text
[B,S,D] → [B,S,4D]
```

例如：

``` text
[2,5,768]
→
[2,5,3072]
```

数学上，对每个 token：

$$
h=xW_1+b_1
$$

其中：

$$
W_1 \in \mathbb{R}^{D \times 4D}
$$

因此：

$$
\mathbb{R}^{D}
\rightarrow
\mathbb{R}^{4D}
$$

`nn.Linear` 只处理 tensor 最后一维，因此 `B` 和 `S` 不变。

------------------------------------------------------------------------

## 6. 为什么要从 D 扩展到 4D？

可以理解成：

> **先把 token 的 representation
> 展开到一个更大的"思考空间"，进行更丰富的 feature
> transformation，再压回原来的 D 维。**

例如：D=4, 则4D=16

所以：4 dimensions→16 dimensions→4 dimensions

这里不是简单把原来的数字复制四遍。`W1` 是 learned parameters，模型在学习如何把原来的 representation 转换成更丰富的intermediate features。

GPT-2 经典设计使用：

$$
D \rightarrow 4D \rightarrow D
$$

但 `4D` 是 architecture choice，并不是所有 Transformer 都必须严格使用 4
倍。

------------------------------------------------------------------------

## 7. Step 2：GeLU

作业使用 GPT-2 风格的 GeLU：

``` python
y = F.gelu(self.linear_in(x))
```

shape：

``` text
[B,S,D]
↓ Linear
[B,S,4D]
↓ GeLU
[B,S,4D]
```

GeLU 不改变 shape，只改变里面的数值。

GeLU 全称： **Gaussian Error Linear Unit**

经典定义：

$$
GeLU(x)=x\Phi(x)
$$

其中：

$$
\Phi(x)
$$

是标准高斯分布的 cumulative distribution function。

------------------------------------------------------------------------

## 8. 为什么需要 GeLU？

如果没有 activation，只有两个 Linear Layers：

$$
xW_1W_2
$$

可以把：

$$
W_1W_2
$$

合并成另一个矩阵：

$$
W=W_1W_2
$$

于是：

$$
xW_1W_2=xW
$$

本质上还是一个 linear transformation。

加入 GeLU 后：

$$
GeLU(xW_1+b_1)
$$

网络获得 non-linearity，因此可以学习复杂得多的 feature transformations。

一句话：**GeLU introduces nonlinearity into the FFN.**

------------------------------------------------------------------------

## 9. Step 3：Linear Out，把 4D 压回 D

``` python
self.linear_out = nn.Linear(4 * D, D)
```

shape：

``` text
[B,S,4D]
→
[B,S,D]
```

例如：

``` text
[2,5,3072]
→
[2,5,768]
```

数学上：

$$
z=yW_2+b_2
$$

其中：

$$
W_2 \in \mathbb{R}^{4D \times D}
$$

所以：

$$
\mathbb{R}^{4D}
\rightarrow
\mathbb{R}^{D}
$$

------------------------------------------------------------------------

## 10. 为什么一定要回到 D？

Transformer block 需要继续做 residual connection，例如：

``` python
x + ffn_output
```

如果：

``` text
x.shape = [B,S,D]
```

那么 `ffn_output` 也必须是：[B,S,D] 才能 element-wise 相加。

所以 FFN 最终必须回到原来的 hidden dimension：

$$
D \rightarrow 4D \rightarrow D
$$

------------------------------------------------------------------------

## 11. Step 4：Dropout

最后：

``` python
z = self.dropout(self.linear_out(y))
```

Dropout 是 regularization。训练时随机 drop 一部分 activations，减少模型过度依赖某些 features。

它不改变 shape：

``` text
[B,S,D]
→
[B,S,D]
```

------------------------------------------------------------------------

## 12. 作业 `forward()` 的计算逻辑

starter code：

``` python
y = F.gelu(...)
z = self.dropout(...)
return z
```

对应：

``` python
def forward(self, x: torch.FloatTensor) -> torch.FloatTensor:
    y = F.gelu(self.linear_in(x))
    z = self.dropout(self.linear_out(y))
    return z
```

第一行：

``` text
D → 4D → GeLU
```

第二行：

``` text
4D → D → Dropout
```

------------------------------------------------------------------------

## 13. 完整 Shape Flow

``` text
x
[B,S,D]

↓ linear_in

[B,S,4D]

↓ GeLU

[B,S,4D]

↓ linear_out

[B,S,D]

↓ Dropout

z
[B,S,D]
```

------------------------------------------------------------------------

## 14. 一个具体例子

假设：

``` text
B = 1
S = 3
D = 4
```

sequence：

``` text
I love cats
```

输入：

``` text
x.shape = [1,3,4]
```

每个 token 有一个 4 维 vector：

``` text
I    → [0.2, 0.5, -0.3, 0.8]
love → [0.7, -0.1, 0.4, 0.2]
cats → [-0.2, 0.9, 0.6, 0.1]
```

因为：

$$
middle\_dim=4D=16
$$

所以：

``` text
Step 1: Linear In
[1,3,4] → [1,3,16]

Step 2: GeLU
[1,3,16] → [1,3,16]

Step 3: Linear Out
[1,3,16] → [1,3,4]

Step 4: Dropout
[1,3,4] → [1,3,4]
```

最终每个 token 又回到 4-dimensional hidden representation。

------------------------------------------------------------------------

## 15. Attention 和 FFN 到底有什么区别？

### Self-Attention

负责： **不同 token 之间的信息交流。**

也就是：mix information across token positions

### Feed Forward

负责： **对每个 token 已经获得的 contextual representation 做 nonlineartransformation。**

也就是：transform each token independently

面试可以说：

> **Self-attention mixes information across token positions, while the
> feed-forward network independently transforms each token
> representation.**

------------------------------------------------------------------------

## 16. 大白话类比

假设三个 token 是三个人：

``` text
Alice
Bob
Charlie
```

Attention 相当于三个人开会，相互获取信息。

FFN 相当于会议结束后，每个人回到自己的房间，独立加工刚才获得的信息。

三个人使用相同的"思考程序"（same FFN parameters），但是各自独立计算。

所以：

``` text
Attention = communication
FFN       = independent processing
```

------------------------------------------------------------------------

## 17. 为什么 Transformer 两个都需要？

可以理解成：

``` text
Attention = Gather / Mix Information

↓

FFN = Process / Transform Information
```

一句话：

> **Attention decides what information to gather; the FFN processes the gathered information.**

------------------------------------------------------------------------

## 18. 和整个 Decoder Block 连起来

``` text
x
[B,S,D]

↓ Masked Multi-Head Self-Attention

[B,S,D]

↓ Residual / Add & Norm

[B,S,D]

↓ Feed Forward

Linear(D,4D)

↓ GeLU

Linear(4D,D)

↓ Dropout

[B,S,D]

↓ Residual / Add & Norm

[B,S,D]

↓ Next Decoder Block
```

------------------------------------------------------------------------

## 19. 一个容易误解的地方

作业 docstring 写：

``` text
The feedforward attention module in a decoder block.
```

严格来说：

> **Feed-Forward Network 不是 Attention。**

`Multi-Head Self-Attention` 和 `Feed-Forward Network` 是 Transformer
block 中两个不同的 sublayers。

------------------------------------------------------------------------

## 20. 面试：What is the Feed-Forward Network in a Transformer?

> **The feed-forward network is a small MLP applied independently to
> each token position. It projects each token from the hidden dimension
> into a larger intermediate dimension, applies a nonlinear activation,
> and projects it back to the original hidden dimension.**

可以补一句：

> **Self-attention mixes information across tokens, while the
> feed-forward network independently transforms each token's
> representation.**

------------------------------------------------------------------------

## 21. 面试：Why expand the hidden dimension?

> **The larger intermediate dimension gives the network more capacity to
> learn nonlinear feature transformations. The representation is then
> projected back to the model hidden dimension so it can continue
> through residual connections and subsequent Transformer blocks.**

------------------------------------------------------------------------

## 22. 面试：Why do we need GeLU?

> **GeLU introduces nonlinearity between the two linear layers. Without
> an activation function, multiple linear layers could collapse into a
> single linear transformation and would have much less expressive
> power.**

------------------------------------------------------------------------

## 23. 最终心智模型

看到：

``` python
y = F.gelu(self.linear_in(x))
z = self.dropout(self.linear_out(y))
```

脑子里直接翻译：

``` text
x [B,S,D]

↓ Linear(D,4D)
把每个 token 展开到更大的 representation space

↓ GeLU
加入 non-linearity

↓ Linear(4D,D)
把每个 token 压回原来的 hidden dimension

↓ Dropout
regularization

↓
z [B,S,D]
```

最重要的一句话：

> **Attention 负责让 tokens 互相交流；Feed Forward 负责让每个 token
> 对交流后的信息独立进行更深的非线性加工。**

英文：

> **Attention mixes information across tokens; the FFN transforms that
> information within each token.**
