# Language Models — Core Concepts

## 1. What is a Language Model?

A **Language Model (LM)** predicts the probability distribution of the **next token** given previous tokens:

[
P(y_t \mid y_1,\dots,y_{t-1})
]

Example:

```text
Input: ["I", "eat", "the"]

P("apple")    = 0.11
P("sandwich") = 0.095
P("computer") = 0.00026
```

A **token** is the basic unit processed by the model. It can be a **word, subword, or character**.

---

## 2. Sequence Likelihood

The probability of an entire sequence is calculated using the **chain rule**:

[
P(Y)=\prod_{t=1}^{T}P(y_t\mid y_{1:t-1})
]

Example:

[
P(I,eat,the,apple)
]

[
=P(I)\times P(eat|I)\times P(the|I,eat)\times P(apple|I,eat,the)
]

**Key idea:** sequence probability = product of each next-token probability.

---

## 3. Statistical N-Gram Models

Traditional language models estimate probabilities by **counting occurrences in a corpus**.

An **n-gram** considers only the previous (n-1) tokens.

Examples:

* Bigram → previous **1** token
* Trigram → previous **2** tokens
* n-gram → previous **n−1** tokens

Example:

[
P(apple\mid eat,the)
]

### Two Major Problems

1. **Parameter explosion:** possible n-grams grow exponentially as (n) increases.
2. **Data sparsity:** unseen sequences receive probability 0.

---

## 4. Neural Language Models

Neural LMs replace the huge **n-gram lookup table** with a **neural network**:

[
\text{previous tokens} \rightarrow NN \rightarrow P(\text{next token})
]

Advantages:

* Can model long histories without exponential parameter growth.
* Continuous representations allow **generalization to unseen sequences**.

Modern LLMs are neural language models.

---

## 5. LM ≠ Text Generation

A language model itself fundamentally outputs:

[
P(\text{next token}\mid\text{context})
]

To generate text, we **sample/select a token from this distribution**, append it to the sequence, and repeat.

> **LM predicts probabilities; a generation procedure uses those probabilities to generate text.**

---

# Conditioned vs. Unconditioned LM

## Unconditioned LM

Only uses previously generated tokens:

[
P(y_t\mid y_{1:t-1})
]

Therefore:

[
P(Y)=\prod_tP(y_t\mid y_{1:t-1})
]

**Past tokens → next token**

Examples: GPT-style / LLaMA models.

---

## Conditioned LM

Uses an additional input sequence (X):

[
P(y_t\mid y_{1:t-1},X)
]

Therefore:

[
P(Y\mid X)=\prod_tP(y_t\mid y_{1:t-1},X)
]

**Input (X) + past output tokens → next output token**

Examples: T5, machine translation, **Seq2Seq**.

---

## Encoder–Decoder Architecture

A common architecture for conditioned LMs:

```text
Input X
   ↓
Encoder
   ↓
Context Representation
   ↓
Decoder + previous y tokens
   ↓
Next Token y_t
```

* **Encoder:** processes input sequence (X).
* **Decoder:** uses (X) and previous outputs (y_{1:t-1}) to predict (y_t).

---

## Notation to Remember

* (X) = **input sequence**
* (Y) = **target/output sequence**
* (y_t) = target token at step (t)
* (\theta) = learned neural-network parameters
* Different papers may swap (X) and (Y), so focus on **input vs. target**, not the letter.

### One-Line Summary

> **LM = next-token probability model. N-grams estimate probabilities by counting; neural LMs learn them with neural networks. Unconditioned LMs use previous tokens only, while conditioned LMs additionally use an input sequence (X).**
# Tokenization, Embedding & Encoder-Decoder

## 1. Tokenization：Text → Tokens

**Tokenizer** 把原始 text 转换成一系列离散的 **tokens**。

**Vocabulary (Vocab)** = 模型所有可用 token 的集合。

常见 tokenization：

| Type                | 思路           | 特点                          |
| ------------------- | ------------ | --------------------------- |
| **Character-level** | 每个字符一个 token | sequence 长，vocab 小          |
| **Word-level**      | 每个单词一个 token | sequence 短，但 vocab 巨大，难处理新词 |
| **Subword-level**   | 单词拆成常见子词     | 现代 LLM 最常见的思路               |

例如：

```text
"hippopotamus"

Word-level:    ["hippopotamus"]
Subword-level: ["hip", "##pop", "##ota", "##mus"]
Character:     ["h","i","p","p","o", ...]
```

**核心 trade-off：**

> token 越细 → vocab 越小，但 sequence 越长。

---

## 2. Tokens → Embeddings

Neural Network 不能直接处理离散的 token，因此需要把 token 转换成连续向量 **Embedding**。

流程：

```text
Text
 ↓
Tokenizer
 ↓
Token
 ↓
Token ID
 ↓
Embedding Matrix
 ↓
Embedding Vector
```

建立一个 **Embedding Matrix $E$**：

$$
E \in \mathbb{R}^{|V| \times d}
$$

其中：

* $|V|$ = **vocabulary size**
* $d$ = **embedding dimension**
* 每一行 = 一个 token 对应的 embedding vector

因此：

> **Token ID 本身没有语义，Embedding 才是 Neural Network 实际处理的连续表示。**

---

# 3. Encoder–Decoder

定义：

$$
X = (x_1, \dots, x_T)
$$

= **Input Sequence**

$$
Y = (y_1, \dots, y_T)
$$

= **Target Sequence**

整体流程：

```text
Input X
  ↓
Tokenization
  ↓
Embedding
  ↓
Encoder
  ↓
Hidden States
  ↓
Decoder ← previous target tokens y₁...yₜ₋₁
  ↓
Predicted Representation
  ↓
Logits
  ↓
Softmax
  ↓
Probability Distribution
```

---

## 4. Encoder

**Encoder input：**

输入 sequence 中每个 token 的 **embedding vector**。

$$
x_1, \dots, x_T
\rightarrow
\text{Embeddings}
\rightarrow
\text{Encoder}
$$

**Encoder output：**

$$
h_1^{\text{enc}}, \dots, h_T^{\text{enc}}
$$

这些叫 **Hidden States**，表示 encoder 对输入 sequence 的 contextual representations。

简单理解：

> **Embedding = token 初始表示**
> **Hidden State = 经过 Encoder、结合上下文后的表示**

---

## 5. Decoder

在第 $t$ 步，Decoder 使用：

1. Encoder 的 **hidden states**
2. 已经看到或生成的 target tokens：

$$
y_1, \dots, y_{t-1}
$$

然后产生当前 step 的预测 representation：

$$
\hat{y}_t
$$

即：

$$
\text{Encoder states} + y_{1:t-1}
\rightarrow
\text{Decoder}
\rightarrow
\hat{y}_t
$$

但 $\hat{y}_t$ **还不是一个 token，也不是 probability**，它是一个连续 vector。

---

# 6. Predicted Vector → Logits

为了知道 vocabulary 中哪个 token 最合适，需要把预测向量 $\hat{y}_t$ 与 vocabulary 中的 token representations 做比较。

课件中表示为：

$$
E\hat{y}_t
\rightarrow
\text{logits}
$$

得到长度为 **vocab size** 的向量：

```text
             logits
apple         2.8
cat           4.1
computer     -1.2
dog           3.7
...
```

**Logit = 每个 token 的 raw score，还不是 probability。**

---

# 7. Softmax：Logits → Probabilities

使用 **Softmax** 将 logits 转换成概率：

$$
P(Y_t = i \mid X, Y_{1:t-1})
============================

\frac{\exp(z_i)}
{\sum_j \exp(z_j)}
$$

其中 $z_i$ 是 token $i$ 的 logit。

如果按照课件中的 embedding notation：

$$
P(Y_t = i \mid x_{1:T}, y_{1:t-1})
==================================

\frac{\exp\left((E\hat{y}_t)_i\right)}
{\sum_j \exp\left((E\hat{y}_t)_j\right)}
$$

因此：

```text
Decoder
   ↓
Predicted Vector
   ↓
Logits
   ↓
Softmax
   ↓
Probability Distribution over Vocabulary
```

最终：

$$
\sum_i P(Y_t = i) = 1
$$

---

# 8. Training：Negative Log Likelihood

训练时我们知道真正正确的 token index，记作 $i^*$。

希望模型：

$$
P(Y_t = i^*) \rightarrow 1
$$

常用 loss 是 **Negative Log Likelihood (NLL)**：

$$
\mathcal{L}
===========

-\sum_{t=1}^{T}
\log
P(Y_t = i^* \mid x_{1:T}, y_{1:t-1})
$$

代入 Softmax：

$$
\mathcal{L}
===========

-\sum_{t=1}^{T}
\log
\left(
\frac{
\exp\left((E\hat{y}*t)*{i^*}\right)
}{
\sum_j \exp\left((E\hat{y}_t)_j\right)
}
\right)
$$

直觉：

* 正确 token probability **高** → loss **小**
* 正确 token probability **低** → loss **大**

因此训练的目标就是：

> **不断提高正确 next token 的 probability。**

在多分类 next-token prediction 中，这与常见的 **Cross-Entropy Loss** 是同一个核心目标。

---

# 9. Generation：Sampling

LM 最终输出的是：

$$
P(Y_t = i \mid \text{context})
$$

也就是整个 vocabulary 的 **probability distribution**，而不是直接输出一个单词。

真正生成 token 还需要 **Sampling Algorithm**：

```text
Probability Distribution
        ↓
Sampling Algorithm
        ↓
Choose Next Token
        ↓
Append Token to Sequence
        ↓
Predict Again
```

不断重复：

$$
y_t \rightarrow y_{t+1} \rightarrow y_{t+2} \rightarrow \cdots
$$

所以：

> **Language Model predicts probabilities; Sampling Algorithm chooses the actual next token.**

---

# 10. Conditioned vs. Unconditioned

## Unconditioned LM

只依赖之前的 tokens：

$$
P(Y_t = i \mid Y_{1:t-1})
$$

```text
Previous Tokens
      ↓
   Decoder
      ↓
Probability
      ↓
 Sampling
```

## Conditioned LM

还依赖额外的 input sequence $X$：

$$
P(Y_t = i \mid X, Y_{1:t-1})
$$

```text
Input X → Encoder ─┐
                   ↓
Previous Y ─────→ Decoder
                   ↓
              Probability
                   ↓
                Sampling
```

---

# 11. 整个流程一条线记住

```text
Text
 → Tokenization
 → Token IDs
 → Embeddings
 → Encoder / Decoder
 → Predicted Representation
 → Logits
 → Softmax
 → Probability Distribution
 → Sampling
 → Next Token
```

## Training vs. Generation

```text
Training:
Probability
 → Compare with Correct Token
 → NLL / Cross-Entropy
 → Backpropagation

Generation:
Probability
 → Sampling Algorithm
 → Next Token
 → Repeat
```

**最核心的四句话：**

> **Tokenizer:** Text → discrete Tokens
> **Embedding:** Tokens → continuous Vectors
> **Neural LM:** Context → Logits → Softmax → Probability
> **Generation:** Probability Distribution → Sampling → Next Token
