# Calibrate Before Use：从大白话到完整 Python 实现

> 论文：Zhao et al. (2021), *Calibrate Before Use: Improving Few-Shot Performance of Language Models*  https://arxiv.org/pdf/2102.09690  
> 用途：SST-2 二分类、few-shot prompting、contextual calibration。  
> 说明：以下代码**补全原题 TODO 并保留旧版 Completions API 风格**，适合学习逻辑；`gpt-5.4-nano` 与 `/v1/completions`、`echo=True`、`max_tokens=0` 不保证兼容。请使用课程指定且支持这些参数的模型。该笔记没有执行真实 API 请求。

## 0. 一句话理解

模型看到一张“白卷”（`N/A`）还偏向给 Positive，那么它做真正的评论分类时也可能偏向 Positive。我们先用 `N/A` 测出这种倾向，再在真实预测上除掉它：

```python
calibrated_scores = original_label_probs / content_free_label_probs
prediction = np.argmax(calibrated_scores)
```

这里的“概率”是模型对标签文本的 token 概率，不一定是已经对所有标签归一化的分类概率。

## 1. 整个代码的数据流

1. `read_data()` 从 SST-2 训练集抽 few-shot 示例，从 validation 集抽带标签的评估题。
2. `create_prompt()` 拼出示范评论及其标签，再拼一条**没有答案**的待测评论。
3. `get_responses()` 请求模型的 token logprobs。
4. `get_label_probs()` 为每道测试题拿到 `Negative`、`Positive` 两个标签的概率。若 top-1 没返回某个标签，使用 `echo=True` 的 teacher-forcing 风格查询补上。
5. `calibrate()` 把测试评论替换为 `N/A`，得到模型的 prompt-induced bias：`p_cf`。
6. `eval_accuracy()` 对比校准前后 `argmax` 预测与 SST-2 正确标签。

**注意：这里“train”只用来挑示范例子，不更新 LLM 参数。**

## 2. 数值直觉：为什么会翻转答案？

真实输入的原始标签概率（顺序 `[Negative, Positive]`）：`[0.40, 0.60]`，会预测 Positive。  
空输入 `N/A` 测出的偏好：`[0.25, 0.75]`，说明模型本来就非常偏向 Positive。  
校正后：`[0.40/0.25, 0.60/0.75] = [1.60, 0.80]`，所以预测 **Negative**。

这不是训练模型，也不是强行让每个真实样本的结果变成 50/50，而是把无内容输入的偏好作为**校正基准**。上面数字是教学示例，不是论文报告的某一组结果。

## 3. 完整补全代码：按课程 starter code 的旧 API 设计

```python
import os
from typing import List, Tuple, Any, Optional

import numpy as np
from tqdm import tqdm
from datasets import load_dataset
from dotenv import load_dotenv
import openai

load_dotenv()

# IMPORTANT: Substitute a model verified to support the *legacy* Completions API,
# echo=True, prompt token logprobs and (if needed) max_tokens=0.
MODEL = os.getenv("LEGACY_COMPLETIONS_MODEL", "YOUR_COMPATIBLE_MODEL")
LABEL_DICT = {0: "Negative", 1: "Positive"}


def read_data(seed: int, train_size: int, test_size: int) -> Tuple[List[str], List[int], List[str], List[int]]:
    """Sample few-shot examples from train and evaluation cases from validation."""
    dataset = load_dataset("stanfordnlp/sst2")
    train_data = dataset["train"].shuffle(seed=seed).select(range(train_size))
    test_data = dataset["validation"].shuffle(seed=seed).select(range(test_size))

    train_sentences = list(train_data["sentence"])
    train_labels = list(train_data["label"])
    test_sentences = list(test_data["sentence"])
    test_labels = list(test_data["label"])
    return train_sentences, train_labels, test_sentences, test_labels


def create_prompt(
    q_prefix: str,
    a_prefix: str,
    few_shot_sentences: List[str],
    few_shot_labels: List[int],
    test_sentence: str,
) -> str:
    """Build examples followed by an unlabeled query."""
    prompt = ""
    for s, label in zip(few_shot_sentences, few_shot_labels):
        if isinstance(label, (int, np.integer)):
            label = "Positive" if label == 1 else "Negative"
        prompt += f"{q_prefix}{s}\n{a_prefix}{label}\n\n"

    prompt += f"{q_prefix}{test_sentence}\n{a_prefix}"
    if a_prefix.endswith(" "):
        prompt = prompt[:-1]
    return prompt


def get_responses(prompts: List[str], echo: bool = False) -> List[Any]:
    """Request completions; requires a compatible legacy-completions model."""
    client = openai.OpenAI(api_key=os.environ.get("OPENAI_API_KEY"))
    responses = []
    max_tokens = 0 if echo else 1

    for prompt in tqdm(prompts, desc="Get response"):
        response = client.completions.create(
            model=MODEL,
            prompt=prompt,
            max_tokens=max_tokens,
            stop=None if echo else "\n",
            logprobs=1,
            echo=echo,
        )
        responses.append(response.choices[0])
    return responses


def _echo_suffix_logprob(response: Any, suffix: str) -> float:
    """
    Find the log probability of the forced label suffix in an echoed response.
    For a one-token label, read that token's logprob; for multiple tokens,
    sum their logprobs. Requires precise token-to-character alignment.

    IMPORTANT: This simple helper assumes token strings concatenate to the
    echoed text exactly (as in many legacy completion implementations).
    If the provider changes echo/token representation, inspect the response.
    """
    info = response.logprobs
    tokens = info.tokens
    token_logprobs = info.token_logprobs
    text = "".join(tokens)
    if not text.endswith(suffix):
        raise ValueError(
            f"Echoed token text does not end with expected suffix {suffix!r}. "
            "Inspect tokenizer/echo response; do not silently take the last token."
        )
    suffix_start = len(text) - len(suffix)
    pos = 0
    selected = []
    for tok, lp in zip(tokens, token_logprobs):
        start, end = pos, pos + len(tok)
        pos = end
        if end > suffix_start:
            if start < suffix_start:
                raise ValueError("Suffix starts inside a token; use token offsets or a compatible label format.")
            if lp is None:
                raise ValueError("No prompt logprob returned for label token.")
            selected.append(lp)
    if not selected:
        raise ValueError("Label suffix has no token logprobs.")
    return float(np.sum(selected))


def get_label_probs(
    responses: List[Any],
    few_shot_sentences: List[str],
    few_shot_labels: List[int],
    test_sentences: List[str],
    q_prefix: str,
    a_prefix: str,
) -> np.ndarray:
    """Return unnormalized [P('Negative'), P('Positive')] per test case."""
    all_label_probs = []
    all_missing_positions = []

    for i, response in enumerate(tqdm(responses, desc="Get initial prob")):
        # For generated completions, first generated token usually follows the prompt.
        top_logprobs = response.logprobs.top_logprobs[0] or {}
        label_probs = np.zeros(len(LABEL_DICT), dtype=float)

        for j, answer in LABEL_DICT.items():
            label = (" " + answer) if a_prefix.endswith(" ") else answer
            if label in top_logprobs:
                label_probs[j] = np.exp(top_logprobs[label])
            else:
                all_missing_positions.append((i, j))
        all_label_probs.append(label_probs)

    all_label_probs = np.asarray(all_label_probs, dtype=float)
    all_additional_prompts = []
    forced_suffixes = []

    for i, j in all_missing_positions:
        prompt = create_prompt(
            q_prefix, a_prefix, few_shot_sentences, few_shot_labels, test_sentences[i]
        )
        answer = LABEL_DICT[j]
        suffix = (" " + answer) if a_prefix.endswith(" ") else answer
        all_additional_prompts.append(prompt + suffix)
        forced_suffixes.append(suffix)

    if all_additional_prompts:
        additional_responses = get_responses(all_additional_prompts, echo=True)
        for idx, (i, j) in enumerate(all_missing_positions):
            logprob = _echo_suffix_logprob(additional_responses[idx], forced_suffixes[idx])
            all_label_probs[i, j] = np.exp(logprob)

    return all_label_probs  # NOT normalized across labels.


def calibrate(
    content_free_input: str,
    few_shot_sentences: List[str],
    few_shot_labels: List[int],
    q_prefix: str,
    a_prefix: str,
) -> np.ndarray:
    """Measure prompt's label preference with a content-free input."""
    prompt = create_prompt(
        q_prefix, a_prefix, few_shot_sentences, few_shot_labels, content_free_input
    )
    p_y = np.zeros(len(LABEL_DICT), dtype=float)

    for i, answer in LABEL_DICT.items():
        suffix = (" " + answer) if a_prefix.endswith(" ") else answer
        response = get_responses([prompt + suffix], echo=True)[0]
        p_y[i] = np.exp(_echo_suffix_logprob(response, suffix))

    if not np.all(np.isfinite(p_y)) or p_y.sum() <= 0:
        raise ValueError("Invalid probabilities for content-free input")
    return p_y / p_y.sum()


def eval_accuracy(
    all_label_probs: np.ndarray,
    test_labels: List[int],
    p_cf: Optional[np.ndarray] = None,
) -> float:
    """Compare true labels with argmax before or after diagonal calibration."""
    num_labels = all_label_probs.shape[1]
    if p_cf is None:
        W = np.eye(num_labels)
        b = np.zeros(num_labels)
    else:
        p_cf = np.asarray(p_cf, dtype=float)
        if p_cf.shape != (num_labels,) or np.any(p_cf <= 0):
            raise ValueError("p_cf must be a positive, length-num_labels vector")
        W = np.diag(1.0 / p_cf)
        b = np.zeros(num_labels)

    corrects = []
    for prob, label in zip(all_label_probs, test_labels):
        score = W @ prob + b
        prediction = int(np.argmax(score))
        corrects.append(prediction == label)
    return float(np.mean(corrects))
```

### 代码里的重要假设（必读）

- **API 兼容**：上述是给课程旧式 completion API 的参考实现；现代模型不一定支持 `echo`、输入 tokens 的 logprobs，或者 `max_tokens=0`。换模型时先查文档，不能只替换 model 名称。
- **标签 token 化**：`Negative`/`Positive` 在不同模型可能被拆成多个 tokens。starter code 使用首 token 的 top-logprobs 作快捷路径；这在标签多 token 时只近似于**首 token 概率**。要严格取标签整体概率，应对**两个标签都**使用 echo/teacher-forcing 计算整个标签的条件 logprob，而不是只补 top-1 缺失标签。本实现的 `_echo_suffix_logprob` 对缺失标签可处理多个 tokens，但仍与快捷路径不完全一致。
- **回显字符串对齐**：不同服务商返回的 tokens 拼接可能与原字符串显示不完全一样。本实现遇到不匹配时会报错，避免静默地算错；实际项目应优先使用 offset 或提供商支持的 token-ID 机制。
- **概率并不必然和为 1**：除两个标签外还有其他可能的续写。计算 `p_cf` 时在类别内部归一化；实际测试分类的 `all_label_probs` 保留未归一化状态。
- **`W @ prob + b` 已足够判断类别**：论文中的 softmax 对 `argmax` 结果不产生影响，因此在 accuracy 计算中可以省略。
- **`p_cf` 很小的数**：分母接近零会放大噪声。实际使用可验证最低概率或尝试平滑，但这属于工程防护，不是此处 starter TODO 的新增要求。

## 4. 每个 TODO 精确对应什么

| 原始位置 | 补全含义 | 一句话理由 |
|---|---|---|
| `read_data`: `train_data/test_data` | 对 split `.shuffle(seed).select(range(n))` | 可复现地选示例和评估样本 |
| `read_data`: sentences/labels | 读取 `['sentence']`、`['label']` | SST-2 的两列 |
| `get_label_probs`: `top_logprobs` | `response.logprobs.top_logprobs[0]` | 获取下一个 token 的候选 logprobs |
| `get_label_probs`: `label_probs` | `np.zeros(2)` | 存两类的概率 |
| `get_label_probs`: `label_probs[j] += ...` | `np.exp(top_logprobs[label])` | logprob 转普通概率 |
| `get_label_probs`: missing positions | `append((i,j))` | 补拿 top-1 中缺失的类别 |
| `get_label_probs`: new prompt | `create_prompt(..., test_sentences[i])` | 还原同一个测试题的上下文 |
| `get_label_probs`: append label | `prompt + (' ' if needed) + label` | 将指定答案作为已知输入，索取其 logprob |
| `get_label_probs`: `prob` | `exp(sum(label token logprobs))` | 计算整个候选标签的概率 |
| `calibrate`: `prompt` | `create_prompt(..., content_free_input)` | 把测试题换成 N/A |
| `calibrate`: `p_y[i]` | 对 echo label 的 logprobs 求指数 | 取得 N/A 下的标签偏好 |
| `calibrate`: normalize | `p_y / p_y.sum()` | 得到 `p_cf` |
| `eval_accuracy`: no calibration | `W=I, b=0` | 不改变原始标签排名 |
| `eval_accuracy`: calibrated | `W=diag(1/p_cf), b=0` | 逆偏好加权 |
| `eval_accuracy`: accuracy | `argmax(W @ prob+b)` 然后与真值比较 | 验证是否改善 |

## 5. 一个完全不调用 API 的自测

```python
import numpy as np

p = np.array([[0.40, 0.60], [0.80, 0.15]])
p_cf = np.array([0.25, 0.75])
true_labels = [0, 0]

print("before:", np.argmax(p, axis=1))          # [1, 0]
print("after: ", np.argmax(p / p_cf, axis=1))   # [0, 0]
print("accuracy before:", np.mean(np.argmax(p, axis=1) == true_labels))  # 0.5
print("accuracy after:", np.mean(np.argmax(p / p_cf, axis=1) == true_labels))  # 1.0
```

## 6. 最容易考的理解题

**Q1：为什么输入 `N/A`？**  因为没有情感内容，仍然偏向某个标签就暴露了 prompt/context 导致的系统性偏差。

**Q2：`echo=True` 为什么有用？**  在支持旧式 prompt logprobs 的接口上，它让我们计算**指定标签作为续写时**的条件概率，而不只看到实际生成的 top token。

**Q3：为什么 `p_cf` 不从真实标签中计算？**  这篇方法想在**不额外使用有标注的校准集**的情况下减少偏差；SST-2 真值只用于最终实验评估。

**Q4：为什么 `W=np.diag(1/p_cf)`？**  被模型先天偏爱的答案分母大、校正后权重低；被模型天然冷落的答案得到相对补偿。

**Q5：有没有改变模型权重？**  没有，是 inference-time 的后处理。

**Q6：能保证提高准确率吗？**  不能。这是针对 prompt bias 的校正，而不是修复知识、推理或全部任务偏差。

## 7. 最后的记忆口诀

**Few-shot prompt → 原始标签概率 `p` → N/A 偏好 `p_cf` → `p/p_cf` → 比较 Accuracy。**

把模型想成阅卷老师：先用白卷测出它偏爱哪个答案，再给正式试卷的分数做校正。
